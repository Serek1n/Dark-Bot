# История изменений

## Релиз и бета
- Бета-функции работают только в бета-версии: бот определяет ветку git (`beta`) или `BOT_CHANNEL`. На релизе они выключены, переключатель в панели заменён пояснением; в бета-версии рядом с названием в меню значок «бета».
- `scripts/update.sh main|beta` — обновление сервера до нужной ветки.

## Архитектура
- **Бот и панель — один процесс.** Каналы, роли и серверы панель берёт из кэша бота (без запросов к Discord), настройки применяются сразу, замки работают для всего. Отдельный процесс `dark-web` не нужен (`pm2 delete dark-web`). Сбой панели не останавливает бота.
- `web/routes/dashboard.js` (923 строки) разбит на 16 файлов в `web/routes/dashboard/`, общие помощники — в `web/utils/common.js`; дубль `hasManageAccess` убран.
- Миграции на **umzug** (`db/migrations`, таблица `schema_migrations`) вместо ручного списка ALTER. Убраны дубли колонок в модели `GuildSettings`.
- Единый **планировщик** (`bot/utils/scheduler.js`): розыгрыши, напоминания, опросы и временные баны срабатывают в срок и не опрашивают базу по таймеру.
- Сессии входа хранятся в основной базе (`web_sessions`), `connect-sqlite3` и второй sqlite3 убраны. После обновления все войдут в панель заново один раз.
- ESLint (`npm run lint`), проверка в CI.

## Музыка и голос
- Плейлист режется до 100 треков.
- Заглушённые (микрофон или звук выключены) не получают награду в голосе и не считаются «компанией» для минимума людей — галочка в разделе «Уровни» (по умолчанию включена).

## Надёжность баланса
- Монеты и кристаллы меняются только атомарными SQL-запросами («баланс = баланс − сумма, если хватает»), а не «прочитать → изменить → сохранить». Это закрывает дюп валюты: параллельные /pay, магазин, /daily, опыт из чата и голоса и панель (отдельный процесс) больше не затирают друг друга.
- /pay — одна транзакция (списание + зачисление); /daily — проверка «прошли ли сутки» внутри самого UPDATE; магазин сначала списывает деньги, потом выдаёт роль и возвращает деньги, если роль выдать не удалось.
- Уровень и кристаллы за уровень начисляются отдельным запросом «только если сохранённый уровень ниже» — дважды не выдаются.
- Транзакции процесса идут по очереди, на каждом соединении SQLite задано ожидание занятой базы.
- /daily больше не пишет «60 мин» вместо «1 ч 0 мин».

## Проект
- package-lock.json теперь в git (одинаковые версии при каждой установке); `@discordjs/opus` — необязательная зависимость.
- Docker: Node 22, yt-dlp, запуск не от root, порт только на 127.0.0.1.
- LICENSE (MIT), CI на GitHub Actions, кроссплатформенная очистка тестовых баз, исполняемые тестовые .sh.

## Оформление панели
- Мягкий свет в углу рабочей области, карточки с объёмом и крупными скруглениями, заголовки страниц крупнее.
- Обзор начинается с самого сервера (значок или буква названия, имя).
- Выбор сервера: крупные плитки с буквой вместо картинки, если у сервера нет значка. Битый значок тоже заменяется буквой.
- Вход: луна со свечением — главный акцент страницы.
- Поля и кнопки: единое кольцо фокуса, одинаковые строки «вкл/выкл», товары магазина — раскрывающиеся строки.
- Мобильный вид: меньшие отступы, одна колонка в формах.
